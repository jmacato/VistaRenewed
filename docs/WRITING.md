# Writing rules

These rules apply to current project documents and assistant replies.
They use the requested ASD-STE100 Simplified Technical English style limits.
Historical records and upstream documents retain their original text.
These rules do not establish formal ASD-STE100 compliance.

## Replies

Give the answer first.
Use prose only.
Use no more than five sentences.
Define technical terms when you introduce them.
Do not use headings, lists, bold text, tables or em dashes.
Do not use contractions.

## Documents

Limit each instruction sentence to 20 words.
Limit each description sentence to 25 words.
Use imperative verbs for procedure steps.
If an instruction has a condition, put the condition before the command.
Use simple tenses and active voice.
Use one term for each meaning.
Define technical terms when you introduce them.
Do not use “should”, “would”, “may” or “might”.
Do not use semicolons or em dashes.
Remove filler and repeated information.
Preserve code exactly.

## Review

Check sentence lengths and terminology.
Compare code blocks before and after each edit.
Check that each procedure retains its original order and conditions.
Check links and technical claims after each rewrite.
